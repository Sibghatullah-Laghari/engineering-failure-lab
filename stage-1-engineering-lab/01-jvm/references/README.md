# Topic
## Learning Objective
Build practical investigation skill for this JVM area using evidence-driven experiments.

## Mental Model
Use a concise model to predict behavior, then validate with observations.

## Engineering Relevance
Connect JVM behavior to failures seen in services, APIs, and production systems.

## Practical Experiments
Run small Java 17 experiments to observe one behavior at a time.

## Case Studies
Solve investigation cases by collecting evidence before proposing fix directions.

## Investigation Questions
Ask what changed, what is retained, what is invoked, and what data confirms it.

## Tools
Java 17, javac, java, javap, jcmd, jmap, jstack, logs, metrics, and profilers.

## Official References
- SPECIFICATION: JVM Specification (Java SE 26)
- SPECIFICATION: Java Language Specification (Java SE 26)
- IMPLEMENTATION-SPECIFIC BEHAVIOR: Oracle JVM docs (Java SE 26)
- IMPLEMENTATION-SPECIFIC BEHAVIOR: GC Tuning Guide (Java SE 26)

## Completion Criteria
Can run experiments, investigate cases with evidence, propose fix directions, and verify outcomes.
